CreceWeb Lumen Lite — human-readable CSS source copies

This directory contains review-friendly formatting of compact CSS files that ship under assets/css/.
The source copies are not enqueued by WordPress and add no frontend requests or transfer bytes.

Mappings:
- source/css/library-kits/components.css -> assets/css/library-kits/components.css
- source/css/library-kits/profiles/aurora.css -> assets/css/library-kits/profiles/aurora.css
- source/css/library-kits/profiles/prisma.css -> assets/css/library-kits/profiles/prisma.css
- source/css/posts-grid.css -> assets/css/posts-grid.css

The corresponding selectors and declarations are preserved; the source copies add formatting for human review.
No transpiler, preprocessor, package manager, or external build service is required to inspect these files.
