# CreceWeb Lumen Lite

**A free companion plugin for Lumen Theme with practical tools for content, navigation, sharing, messaging and everyday WordPress workflows.**

CreceWeb Lumen Lite extends the Lumen Theme with useful site-building and management features while keeping the core theme lightweight.

> **Free practical tools. Added only when you need them.**

---

## What Lumen Lite adds

Lumen Lite includes practical tools for real-world WordPress websites, including:

- Lumen Library;
- reusable Gutenberg sections and pages;
- reading progress;
- automatic table of contents;
- sharing tools;
- related content;
- advanced floating action;
- site-wide messaging;
- menu enhancements;
- per-device menu visibility;
- highlighted menu links;
- footer tools;
- performance-conscious settings and integrations.

Messaging currently supports providers such as:

- WhatsApp;
- Telegram;
- Messenger;
- Signal.

Lumen Lite is designed to remain useful as a free plugin and does not require Lumen Pro.

## Installation

The recommended installation method is through WordPress.org:

[Install CreceWeb Lumen Lite](https://wordpress.org/plugins/creceweb-lumen-lite/)

You can also install the plugin manually by placing the plugin directory inside:

```text
/wp-content/plugins/
```

Then activate **CreceWeb Lumen Lite** from:

```text
Plugins → Installed Plugins
```

## Reporting bugs

Please use the repository **Issues** section for reproducible bugs affecting Lumen Lite.

Before opening an issue:

- update to the latest stable Lumen Theme and Lumen Lite releases;
- confirm the issue still occurs with current WordPress;
- include your WordPress and PHP versions;
- provide clear reproduction steps;
- mention whether Lumen Pro is active;
- identify the affected Lite feature;
- avoid including credentials, private URLs or sensitive information.

Security vulnerabilities should **not** be reported as public issues. See [SECURITY.md](SECURITY.md).
