Fonts
No font files or remote font services are bundled or loaded. The plugin uses WordPress/admin/theme typography.

Translations
English is the plugin source language. Translation catalogs are maintained outside the public plugin package for import/review on translate.wordpress.org. WordPress.org-hosted installations receive available translations through official WordPress language packs.

Third-party libraries
No third-party JavaScript, CSS, font, icon pack, analytics SDK, social SDK, or remote executable library is bundled by Lumen Lite. WordPress core-provided dependencies are referenced through WordPress APIs and are not redistributed.
